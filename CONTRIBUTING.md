# Contributing to Little Lemon

Thank you for your interest in contributing to Little Lemon! We welcome contributions from the community to improve this Django-based restaurant management system.

## How to Contribute

### 1. Fork the Repository
- Click the **Fork** button on the repository.
- Clone your fork:
  ```sh
  git clone https://github.com/YOUR-USERNAME/LittleLemon.git
  cd LittleLemon
  ```
- Add the original repository as an upstream remote:
  ```sh
  git remote add upstream https://github.com/Dhanrajshyam/LittleLemon.git
  ```

### 2. Create a Feature Branch
- Always create a new branch for your changes:
  ```sh
  git checkout -b feature/your-feature-name
  ```
- Make your changes and commit them:
  ```sh
  git commit -m "Add your commit message here"
  ```
- Push the branch to your fork:
  ```sh
  git push origin feature/your-feature-name
  ```

### 3. Submit a Pull Request (PR)
- Go to the original repository: https://github.com/Dhanrajshyam/LittleLemon
- Click **New Pull Request**.
- Select your fork and feature branch.
- Fill in the PR template and submit it for review.

## Contribution Guidelines
- Follow **PEP 8** for Python coding style.
- Ensure that all tests pass before submitting a PR:
  ```sh
  python manage.py test
  ```
- Keep PRs focused and minimal.
- Include documentation and comments for your code.

## Reporting Issues
- Check the existing issues to avoid duplicates.
- If creating a new issue, describe the problem clearly.
- Provide steps to reproduce the issue if possible.

## Code of Conduct
All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
