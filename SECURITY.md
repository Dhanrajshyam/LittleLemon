# Security Policy

## Reporting a Vulnerability

If you discover a security issue in Little Lemon, please report it responsibly by following these steps:

1. **Do not disclose publicly**: To prevent potential abuse, do not report vulnerabilities in public issues or discussion forums.
2. **Contact us**: Send an email to [shyamjck@gmail.com] with details of the vulnerability.
3. **Provide Details**: Include steps to reproduce, potential impact, and any proposed fixes if available.
4. **Response Time**: We aim to respond within **48 hours** and resolve the issue as soon as possible.

## Supported Versions
| Version | Supported |
|---------|------------|
| 1.x.x   | ✅ Supported |
| < 1.0.0 | ❌ No longer supported |

## Security Best Practices
- Ensure that all dependencies are up-to-date.
- Use secure authentication and authorization mechanisms.
- Follow Django’s security best practices.

Thank you for helping keep Little Lemon secure! 🔒
